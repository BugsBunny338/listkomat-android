# Play Console → App content: answer sheet

Click-through answers for every declaration, so none needs thinking on the go.
(Policy → App content in the console; items appear before the first release.)

- **Privacy policy**: https://bugsbunny338.github.io/listkomat-web/privacy
- **Ads**: No, the app contains no ads.
- **App access**: All functionality is available without special access
  (no login; note: purchases require a Czech SIM, but reviewers can browse
  everything without one).
- **Content ratings questionnaire**: category *Utility/Productivity*;
  answer **No** to all content questions (no violence, sexuality, language,
  controlled substances, gambling, user-generated content, location sharing
  with other users). Expected outcome: rated 3+/Everyone.
- **Target audience**: 18+ (or 13+; the app is not directed at children —
  do NOT tick any child-directed option, it triggers Families policy).
- **News app**: No.
- **COVID-19 tracing/status**: No.
- **Data safety**: collects **nothing**, shares **nothing**.
  - Location: used on-device only to pick the nearest city, never transmitted.
  - No analytics, no third-party SDKs sending data, no accounts.
  - Data encrypted in transit: n/a (no user data leaves the device).
  - Deletion request mechanism: n/a (nothing collected).
- **Government app**: No.
- **Financial features**: None. (Premium SMS is carrier billing outside the
  app; the app itself performs no payment — it only prefills a message the
  user sends manually. Declare "My app doesn't provide any financial
  features".)
- **Health apps**: No.
